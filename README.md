# Jokenpô ✊✋✌️

🇧🇷 **Português** | 🇬🇧 **English below**

Um jogo de **Pedra, Papel e Tesoura** desenvolvido com HTML, CSS e JavaScript.

O projeto foi criado durante meus estudos de desenvolvimento web para praticar fundamentos de JavaScript, lógica de programação e manipulação do DOM, transformando um exercício de lógica em uma pequena aplicação web interativa.

## 🎮 Como funciona

Escolha entre:

- ✊ Pedra
- ✋ Papel
- ✌️ Tesoura

O computador faz uma escolha aleatória e o jogo determina o vencedor da rodada.

O placar é atualizado automaticamente durante a partida.

## ✨ Funcionalidades

- Escolha aleatória do computador
- Lógica de vitória, derrota e empate
- Placar dinâmico
- Atualização da interface através do DOM
- Feedback visual para cada resultado
- Animações CSS
- Layout responsivo para desktop e mobile
- Design inspirado na estética vaporwave

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript

## 🧠 O que pratiquei

Durante o desenvolvimento deste projeto, pratiquei conceitos como:

- Funções e parâmetros
- Arrays
- Objetos
- Condicionais (`if / else`)
- Operadores lógicos (`&&` e `||`)
- `Math.random()` e `Math.floor()`
- Eventos com `addEventListener`
- Manipulação do DOM
- `textContent`
- `classList`
- Estado e atualização de placar
- Animações com `@keyframes`
- Responsividade com media queries
- Debugging com DevTools
- Git e fluxo de trabalho com branches

## 🚀 Possíveis melhorias futuras

O projeto está concluído como exercício de fundamentos de JavaScript, mas algumas funcionalidades podem ser adicionadas futuramente:

- Melhorias de acessibilidade
- Efeitos sonoros
- Modo "melhor de 3" ou "melhor de 5"
- Histórico de partidas

# Jokenpô — Rock Paper Scissors ✊✋✌️

A **Rock Paper Scissors** game built with HTML, CSS, and JavaScript.

This project was created during my web development studies to practice JavaScript fundamentals, programming logic, and DOM manipulation, turning a simple logic exercise into an interactive web application.

> The game interface is currently in Portuguese.

## 🎮 How it works

Choose between:

- ✊ Rock
- ✋ Paper
- ✌️ Scissors

The computer randomly selects its move and the game determines the winner of each round.

The score is automatically updated as you play.

## ✨ Features

- Random computer selection
- Win, loss, and draw logic
- Dynamic score tracking
- DOM-based interface updates
- Visual feedback for each result
- CSS animations
- Responsive layout for desktop and mobile
- Vaporwave-inspired design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 🧠 What I practiced

While building this project, I practiced concepts including:

- Functions and parameters
- Arrays
- Objects
- Conditional statements (`if / else`)
- Logical operators (`&&` and `||`)
- `Math.random()` and `Math.floor()`
- Event handling with `addEventListener`
- DOM manipulation
- `textContent`
- `classList`
- State and score updates
- CSS animations with `@keyframes`
- Responsive design with media queries
- Debugging with DevTools
- Git and branch-based workflow

## 🚀 Possible future improvements

The project is complete as a JavaScript fundamentals exercise, but some features could be added in the future:
